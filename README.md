`entry.png` is a 1024×1024 news-collage front page for a single day —
25 November 2026: a red masthead banner with the date, a hand-drawn globe
with stylised continents, orbit ring and location pins, four headline
panels (World, Markets, Tech, Climate), and a bottom ticker band covering
sport, culture, science and people.

## Build

    python3 draw_image.py   # writes entry.png (Pillow only)
    node main.ts            # same, via the entry point

Python 3 with Pillow; `main.ts` is a short launcher that runs
`draw_image.py` — the image is rendered programmatically, never embedded.
